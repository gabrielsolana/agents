I wrote a Python program in the sandbox to compute the first 1,000,000 terms of the Leibniz series

1 - 1/3 + 1/5 - 1/7 + ...

and multiply the result by 4.

File created: `leibniz_pi.py`

Program output after running it:
`3.1415916535897743`

This is the approximation of π produced by summing 1,000,000 terms of the series and multiplying by 4.
